All requests must be POST and include your API key in the header:
X-API-Key: your_key_here

eSIM

1. Get Countries

POST /esim/countries
{
  "key": "YOUR_API_KEY"
}

2. Get Plans

POST /esim/plans
{
  "key": "YOUR_API_KEY",
  "country": "US"
}

3. Buy eSIM

POST /esim/buy
{
  "key": "YOUR_API_KEY",
  "package": "PACKAGE_ID"
}

Response includes: order, qr, lpa, iccid

Proxies

1. List Products

POST /proxies/list
{
  "key": "YOUR_API_KEY"
}

2. Buy Proxy

POST /proxies/buy
{
  "key": "YOUR_API_KEY",
  "product": 3,
  "plan": 5,
  "location": 16,
  "quantity": 1
}

Response includes: order, proxies (array of proxy strings)
